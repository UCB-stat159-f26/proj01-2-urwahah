# Project 1

**Title**: Replicating Temperature Anomalies Graphics

**Author**: Urwa Irfan

**Date started**: 21 Sep 2026

**Date last updated**: 24 Sep 2026

**Description**: This project attempts to replicate three graphics from NASA Goddard Institute for Space Studies (GISS) Surface Temperature Analysis ([GISTEMP](https://data.giss.nasa.gov/gistemp/)) version 4, as well as a [modified version of a GISTEMP graphic](https://www.nytimes.com/interactive/2019/02/06/climate/fourth-hottest-year.html) from the New York Times. This project was completed for an assignment for STAT 259 at UC Berkeley in Fall 2026.

**Inputs**: 
- GISTEMP data from [NASA GISS](https://data.giss.nasa.gov/gistemp/data_v4.html)
- GISTEMP uncertainty data from [NASA GISS](https://data.giss.nasa.gov/gistemp/uncertainty/quantification.html)

**Dependencies**: R 4.6.1, with the following packages: 
- `tidyverse`
- `ggplot2`
- `scales`
